# DEMO FIXTURES - SIH 2026 DEMONSTRATION MODE (Step 14)

**Everything in this folder is FAKE, synthetic, demonstration data**
generated by `scripts/make_demo_fixtures.py` (see `manifest.json`).

- All documents are clearly-bannered SPECIMEN images with fabricated
  identities (the fictional UTO / UTOSLAND personas). No real identity
  document or real personal data is used anywhere.
- Demo results are labeled DEMONSTRATION/SIMULATED in the API and UI.
- This mode never fakes real government verification: registry lookups
  stay MOCK-stamped, the face module is a real 1:1 embedding compare,
  and every pipeline stage runs exactly as in production.

## The four scripted cases

1. **case1_valid** - valid document: OCR ok, validation passes, no
   obvious tampering, face MATCH, low risk, audit recorded.
2. **case2_tampered** - spliced portrait + altered printed DOB:
   tampering indicators, increased risk, human review, audit recorded.
3. **case3_identity_mismatch** - genuine document + DIFFERENT presenter:
   validation passes, face verification fails, high risk, review.
4. **case4_low_quality** - blurred/low-quality scan: low OCR confidence,
   inconclusive where appropriate, human review.

## Fixture calibration notes (Step 14)

These images are calibrated end-to-end against the real modules so the
scripted outcomes reproduce reliably (measure with --check-faces):

- **Face fixtures.** A's probe matches A's page portrait at similarity
  ~0.86 (MATCH threshold 0.363); B's probe scores ~0.24 against it
  (NO_MATCH ceiling 0.25) via structural geometry differences plus a
  per-person face-region grain post-pass and repainted irises.
- **MRZ.** Printed at 0.66 scale: at 0.62 RapidOCR merges one '<' pair
  (43 chars) and the composite check digit fails. The MRZ box ends well
  above the bottom SPECIMEN banner (shared box glyphs merge lines).
- **Page look.** Crisp machine print in one warm-brown ink family
  (PAGE_INK) with a faint guilloche wave pattern (PAGE_GUILLOCHE,
  ~30 gray levels under the page). Measured effects: mixed hues trip
  the stamp ink cue; without the guilloche the empty page middle
  flags as flat 'pasted patch' tiles; global grain/blur breaks MRZ
  OCR or creates noise outliers; a locally softened portrait becomes
  a noise/sharpness outlier. The calibrated page reads
  no_obvious_manipulation (risk ~4) like the repo's own valid sample.
- **Case 2 lesson.** The spliced synthetic portrait can still
  similarity-MATCH A's probe (SFace keys on coarse structure) — the
  forensic tampering stage (JPEG metadata + DOB-patch ink cue) is
  what catches this case. Defense in depth, honestly labeled.
